# 通用工具

自建工具现在可选自动启动及网址范围；内置工具仍需手动点击。自动模式生命周期与权限详见 [自定义工具接口](CUSTOM_TOOLS.md)。

侧边栏的“工具”页独立于站点改造，不配置 URL 匹配规则。内置工具不使用模型 Key、不调用 AI，也不要求开启用户脚本。自建工具支持 AI 生成和手写代码，执行时需要开启用户脚本，见 [自定义工具接口](CUSTOM_TOOLS.md)。

## 使用

1. 在普通 HTTP/HTTPS 网页点击 Chrome 工具栏的 PageCraft 图标。
2. 打开“工具”，选择可视区域截图、整页截图或提取页面文本。
3. 首次使用可能请求当前网站权限；截图优先使用 activeTab。若临时权限不可用，点击错误下方的“授权截图”，明确同意 Chrome 的所有网站访问权限弹窗，再重新运行。拒绝授权不会反复弹窗。
4. 结果在工具页预览，点击下载按钮导出 PNG 或 TXT；文本也可复制。

截图期间保持目标标签页处于活动状态，不切换、滚动或缩放页面。管理页可以提取页面文本，截图建议从目标网页侧边栏运行。未连接扩展的浏览器预览仅展示界面。

## 整页截图

对当前已加载主文档进行横向和纵向分块捕获，按实际截图像素比例拼接。固定和 sticky 元素保留在首块，其后临时隐藏，结束后恢复。暂停 CSS 动画、禁用平滑滚动和滚动吸附；失败、取消时恢复滚动位置及样式。页面端设有 15 秒无操作恢复定时器，以应对后台意外停止。

目前不支持无限滚动的完整历史、虚拟列表未挂载内容或嵌套滚动容器的完整内容。尺寸变化时停止并提示重试；视频、canvas 动画、第三方 iframe 和自定义布局可能存在差异。暂不支持分段导出：超过 60 个分块、单边 32760 像素、3200 万像素总面积或 20MB PNG 时提示改用可视区域截图。任务最长 2 分钟。

## 页面文本

优先提取 main、role=main 或 article，缺失时提取 body。跳过表单、可编辑内容、隐藏元素及 PageCraft 增加的节点；不保证达到专业文章解析器的正文识别精度。最多扫描 50000 个文本节点、提取 200000 字符，超过时明确提示截断。

## 数据与权限

不新增安装时网站权限，不申请 debugger 或 cookies 权限。结果仅保留在当前扩展界面的内存中；关闭界面即丢失，下载后由用户管理。截图按像素捕获，可能包含输入框内容或个人信息，并不会自动脱敏。工具不会将截图或文本发送给模型。

## 验证

单元测试覆盖工具注册及拼接坐标/尺寸上限；Chromium 集成测试验证真实 2400px 整页截图三段颜色像素、可视区域高度、取消和滚动/固定元素恢复、文本排除输入与可编辑内容、TXT 下载及 320/390/1024px 布局。

无头测试的临时扩展副本预授予 all_urls 以代替无法点击的原生授权流程。发布 dist 仅将其声明为可选权限，必须经用户点击并确认才授予。原生授权弹窗仍需在普通 Chrome 环境人工验收。
