# 改造运行器接口

> 当前开发模式（优先于下文旧版安全设计）：已移除生成代码的 API、标签、属性、动态访问、CSS 及代码长度限制，并放宽 USER_SCRIPT CSP。只检查 JavaScript 语法、返回数据结构和非空结果。任意生成代码可能读取页面数据、联网或产生不可撤销副作用，仅用于测试网页。API Key 隔离、站点授权、浏览器自身限制、任务取消和版本管理仍保留。下文原有静态安全检查描述不再代表当前实现。

脚本保存为同步函数体，执行时接收 `ctx`。不要在脚本最外层声明入口函数；可返回一个同步清理函数。每文档同一版本只初始化一次；路由、版本、启用状态变化时清理后重新判断。

| 接口 | 用途 |
| --- | --- |
| `ctx.append(parent, node)` | 插入新节点，自动标记并在清理时移除 |
| `ctx.style(css)` | 添加可清理样式，也可使用返回数据中的 `css` 字段 |
| `ctx.on(target, event, callback)` | 注册事件，清理时移除；捕获回调异常 |
| `ctx.observe(target, callback)` | 监听子节点变化，150ms 节流；需自行先执行一次初始化 |
| `ctx.interval(callback, ms)` | 注册可清理定时器，最小 250ms |
| `ctx.timeout(callback, ms)` | 注册可清理延时 |
| `ctx.attribute(element, name, value)` | 修改并在清理时恢复属性 |
| `ctx.text(element, value)` | 修改并恢复文本；不要用于含需保留子元素的容器 |
| `ctx.onCleanup(callback)` | 注册其他同步清理逻辑 |
| `ctx.copy(text)` | 仅在用户点击后复制文本 |
| `ctx.download(filename, text)` | 仅在用户点击后导出文本文件 |

不要直接删除原始网页节点或覆盖 HTML。不能自动提交表单、读凭证、访问扩展 API 或联网。静态检查采用保守规则，可能拒绝某些无害的动态代码；可以重写为显式 DOM 操作。

用户脚本注册在其匹配规则对应的源范围，具体路径及排除规则由运行器判断，这样 SPA 从未匹配路径进入匹配路径时也能运行。URL 检查间隔为 750ms。每 5 秒查询有限执行许可，撤销权限或关闭改造时停止已有运行；浏览器后台定时器节流可能延迟检查。

`onUserScriptMessage` 只接受运行状态和执行许可查询。常规管理消息只接受扩展自己的 index/options 页面，不对网站或用户脚本开放。错误状态不回传脚本任意异常正文，避免其包含敏感 DOM 文本。

多项改造按创建时间初始化。不要假定不同改造修改同一元素时能够无冲突合并。手工脚本绕过清理约定后，刷新是完整恢复的兜底。
