# PageCraft 本地开发版隐私说明

2026-10-28 自动工具：用户明确开启并保存后，脚本可在授权匹配页面加载时自动执行，不再要求每次点击。全站模式需授权 HTTP/HTTPS 网站范围，指定网站模式仅请求对应来源。脚本可能读取页面、联网及产生副作用；开启自动启动不改变其能力。自动启动配置随本地版本存储，关闭开关并保存或删除可停用；撤销网站权限后运行器定期清理。AI 生成会附带自动/手动生命周期要求，不自动发送额外页面内容。

自建工具（2026-10-27）：工具代码、需求、说明、默认参数及最近 10 个版本存入本机扩展存储。AI 生成会发送需求及修订所需旧代码；只有勾选“附带当前页面摘要”时才采集该摘要并发送。手写、保存和运行不需要模型 Key。自建代码可自行联网及修改页面，不能将“内置工具不外发数据”的承诺延伸到任意自建代码。运行桥接不提供模型 Key。结果仅在界面中暂存，下载后由用户管理。

通用工具仅在用户点击时处理当前网页，截图和提取文本不会发送给 AI，也不写入扩展长期存储。结果仅保留在界面内存，用户可下载至本机。截图可能包含表单输入及可见个人信息，不做自动脱敏。截图优先使用 activeTab；失败后可由用户点击“授权截图”，通过 Chrome 弹窗授予可选的所有网站访问权限。不会安装时请求全部网站权限；授权后可在扩展设置中撤销。

> 当前开发模式（优先于下文旧版安全设计）：已移除生成代码的 API、标签、属性、动态访问、CSS 及代码长度限制，并放宽 USER_SCRIPT CSP。只检查 JavaScript 语法、返回数据结构和非空结果。任意生成代码可能读取页面数据、联网或产生不可撤销副作用，仅用于测试网页。API Key 隔离、站点授权、浏览器自身限制、任务取消和版本管理仍保留。下文原有静态安全检查描述不再代表当前实现。

更新日期：2026-10-23。

PageCraft 不设自建服务器、账号系统或遥测服务。API Key、模型设置、改造及最近版本保存在本机 Chrome 扩展存储；草稿放在浏览器会话存储。清除浏览器/扩展数据或卸载扩展会丢失这些数据。

用户点击生成时，将需求、必要页面摘要、去掉查询参数和 fragment 的页面 URL，以及修订所需的旧脚本发送到已保存的服务商：OpenAI、DeepSeek、Google Gemini 或 Claude。各服务商分别保存授权，未授权不能发送页面内容；不会自动切换服务商。OpenAI 请求设置 `store: false`；这不代表服务商完全不保留数据，服务端处理由对应账户与服务商当前政策决定。

采集器跳过输入框、textarea、select、contenteditable、隐藏内容及 script/style，不读取 Cookie 或网页存储。可见文本、标题、元素 ID 和类名仍可能包含个人信息。可在生成前采集和查看摘要，或选择更小的区域；不要在不希望内容外发的页面生成改造。

API Key 按服务商隔离，只用于受信任后台发往对应官方域名的请求：`api.openai.com`、`api.deepseek.com`、`generativelanguage.googleapis.com`、`api.anthropic.com`。Key 不进入 URL、prompt、页面脚本、设置读取回复或运行记录。本机存储不等同于加密保险库，具有本机账户或扩展调试权限的人可能读到它。

权限用途：

- `storage`：本地改造、设置、草稿和任务状态。
- `sidePanel`：侧边栏。
- `tabs`：显示当前页面信息，并找到应更新/清理的已打开标签页。
- `activeTab`、`scripting`：用户操作后采集必要页面结构。
- `userScripts`：执行用户创建的改造。
- `alarms`：清除超过撤销期限的删除数据。
- 四家服务商主机权限：访问对应官方 API。
- 可选 HTTP/HTTPS 主机权限：仅在用户选择目标规则并授权后用于采集和运行。

静态检查仅降低风险，不能证明任意 JavaScript 安全。网页和脚本之间共享 DOM，不应将它视作隔离敏感数据的安全边界。

当前开发版允许读取和写入 `href`，包括 `setAttribute("href", ...)`。检查器不验证链接协议或目标，危险协议及外部链接存在风险；此变更不放开 `src`、`createElementNS` 或事件属性。

当前开发版已取消 `document.createElement` 的标签白名单和字面量参数限制，允许任意标签，包括 script、iframe 和自定义元素。其他受限 API、属性和 CSS 检查仍保留，但不保证这些元素无副作用；标签放行增加了脚本执行、资源加载及页面行为变化的风险。

设置页可清除 Key 或全部本地数据。清除后请刷新曾经应用改造的网页，确保原始页面恢复。此说明是本地开发版说明，正式上架前须补充运营主体、联系方式及实际分发版本信息。
